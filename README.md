# 草叢大亂鬥 ⚽📝

7 對 7 的俯視角足球對戰遊戲，結合小學三年級上學期的數學練習。每打完一場比賽，都要先完成 2 分鐘的數學挑戰；答對越多題，拿到的金幣和獎勵越多。

## 怎麼開始

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝或架伺服器。電腦和手機都可以玩。

1. 首頁用 `‹` `›` 切換**已解鎖**的英雄。選哪個英雄就等於選了他所屬的**隊伍**和**位置**。
2. 按 **出擊!** 開始比賽。你操控自己選的英雄，其他 13 名隊友與對手都由電腦控制。

## 遊戲流程

```
打開連結 → 第一場直接開打 → 比賽結算(戰力能量、勝場)
        ↑                          ↓
   領取獎勵、升級英雄 ← 2 分鐘數學挑戰(金幣、暴擊、代幣)
```

- 第一場比賽不用先做數學，打開就能玩。
- **每一場比賽結束後，都一定要先完成數學挑戰**，才能開始下一場。就算重新整理網頁也跳不過，首頁的按鈕會變成「📝 先做數學」。

## 勝負規則

| 項目 | 規則 |
| --- | --- |
| 比賽時間 | 3 分鐘 |
| 獲勝條件 | 先進 **3 球**的隊伍立刻獲勝；時間到則比分高者勝，同分算平手 |
| 進球 | 球進入對方球門區域就得分。藍隊攻右邊、紅隊攻左邊，踢進自家球門會算對方得分 |
| 進球後 | 停頓約 2 秒後重新開球：球回到中圈，所有人回到開場位置並補滿血量 |

### 比賽獎勵：戰力能量

| 結果 | ⚡ 戰力能量 | 其他 |
| --- | --- | --- |
| 勝利 | +40～60 | 🃏 **雙倍卡**：接下來那場數學挑戰的金幣全部 ×2 |
| 平手 | +20～25 | |
| 落敗 | +10～15 | 安慰獎，維持打下一場的動力 |

比賽本身不給金幣，金幣都要從數學挑戰拿。

### 每日勝場里程碑

勝場每天重新計算（以裝置的日期為準）。

| 當日累計 | 獎勵 |
| --- | --- |
| 3 勝 | ⭐ 星光代幣 ×1 |
| 5 勝 | 🎫 升級券 ×1：任選一位英雄免費升一級（不用花能量） |

## 2 分鐘數學挑戰

題目以**小學三年級上學期**的程度為主，用畫面上的數字鍵盤作答（電腦也可以直接打數字、按 Enter 送出、Backspace 刪除）。答錯不扣分，會顯示正確答案；挑戰結束後，也會列出答錯的題目讓小朋友再看一次。

| 項目 | 獎勵 |
| --- | --- |
| 每答對 1 題 | 💰 15 金幣（基本題），💰 20 金幣（進階題） |
| 雙倍卡生效時 | 每題金幣 ×2（剛打贏一場就會有） |
| 連續答對 5 題 | ⚡ **能量暴擊**：結算時二選一，⚡ 戰力能量 +30，或 💰 金幣 +50（雙倍卡生效時 +100）。每連對 5 題觸發一次 |
| 單次答對 12 題以上（開發環境 3 題） | ⭐ 星光代幣 ×1 |

2 分鐘大約可以答對 10～15 題，能拿到 150～300 金幣。玩 3～4 場就買得起一個 1,000 金幣的武裝配件。

### 題型

| 單元 | 基本題（15 金幣） | 進階題（20 金幣） |
| --- | --- | --- |
| 10000 以內的數 | 位值（某一位的數字是多少）、千百十一的合成 | |
| 加減法 | 三位數加減 | 四位數加減（含進位、退位）、四位數應用題 |
| 乘法 | 九九乘法、乘法應用題 | 二位數 × 一位數、三位數 × 一位數 |
| 除法 | 九九範圍的整除、平分應用題 | 有餘數的除法（填商或餘數） |
| 長度 | 公分 ↔ 毫米 | 幾公分幾毫米 ↔ 毫米 |
| 時間 | | 時 ↔ 分、分 ↔ 秒 |
| 分數 | 平分的意義、單位分數、1 = 幾分之幾 | |

題庫寫在 [js/math.js](js/math.js) 的 `QTYPES`，每種題型可以調整金幣（`c`）和出題比重（`w`）。

## 英雄養成

### 解鎖英雄
一開始可以用的英雄是**磐石、疾風、雷雷、月光**，其他英雄要用 **⭐ 星光代幣 ×3** 解鎖。到「角色」頁點開英雄就能解鎖。

### 英雄等級
在「角色」頁可以用 ⚡ 戰力能量替英雄升級，最高 **Lv.10**。每升一級，該英雄的**血量和傷害各 +5%**。

| 升級 | 需要的能量 |
| --- | --- |
| Lv.1 → 2 | ⚡ 100 |
| Lv.2 → 3 | ⚡ 150 |
| 之後每級 | 再多 50 |
| Lv.9 → 10 | ⚡ 500 |

也可以用 🎫 升級券直接升一級。

### 造型
用 **⭐ 星光代幣 ×3** 在商店解鎖造型（黃金、暗影、熔岩、冰晶、糖果、叢林），會換掉英雄的主色。解鎖後每位英雄都可以在「角色」頁各自套用，也可以隨時改回原色。

## 場上機制

### 帶球與射門
- 碰到球就能帶著球走。
- 球在腳邊時按攻擊鍵，會把球往瞄準的方向踢出去，而不會射擊。
- 爆炸類攻擊也會把附近的球炸開。

### 攻擊、大招、超能力
- **普通攻擊**：每個角色的攻擊方式都不一樣，像是散彈、狙擊、拋物線炸彈或近身斬擊。
- **大招**：攻擊和命中敵人都會累積大招能量，集滿 100% 後按大招鍵施放，施放後能量歸零。
- **超能力**：每個角色各有一招，用完要等冷卻（4～9 秒），不需要累積能量。
- **翻滾**：短暫衝刺，翻滾中**不會受到傷害**，冷卻 3.5 秒。

### 受傷、擊倒與回血
- 血量歸零就會被擊倒，**3 秒**後在自己的開場位置重生。
- 連續 4 秒沒有受到攻擊，就會開始自動回血（每秒 25 點）。
- 被擊倒時會掉落一個綠色**強化方塊**，任何人撿到都能得到：
  - 血量上限 +10
  - 傷害 +10%（可以累加；被擊倒時強化全部歸零）

### 草叢
躲進草叢後，敵人就看不到你。不過敵人靠得很近（約 2 個身位內）時還是會被發現。

## 好友房間（多人連線）

首頁的「👥 好友房間」可以跟朋友一起玩。只做好友房間，不跟陌生人配對。

1. 一位小朋友按「🏠 建立房間」，畫面會顯示**房間代碼**，按「📋 複製邀請連結」可以把連結傳給朋友。
2. 朋友打開邀請連結會直接進房間，也可以在「好友房間」輸入代碼後按「加入房間」。
3. 每個人在房間裡用 ‹ › 選自己的英雄。選哪隻英雄就決定隊伍和位置，同隊同位置撞到時會自動改坐其他空位。
4. 大家都準備好之後（沒有數學挑戰沒做完），**房主**（名字前有 👑）按「⚽ 開始比賽」。
5. 比賽結束後，每個人在自己的裝置上做數學挑戰、各自領獎勵，做完回到房間，就能再開下一場。

| 規則 | 說明 |
| --- | --- |
| 人數 | 一個房間最多 4 位真人，其他位置由電腦補滿 7 對 7 |
| 升級與配件 | 在好友房間裡一樣有效 |
| 聊天 | **不提供文字聊天**，只能送預設的表情和短語（👍😂😮😢😡🎉、好球!、傳給我!、加油!、小心!、謝謝!、再來一場!），每秒最多送一次。房間裡和比賽中（右上角 😊）都能送 |
| 名稱 | 有登入就用帳號名稱，沒登入顯示「玩家」加兩位數字 |
| 中途離開 | 比賽中有人離開，他的角色改由電腦接手 |
| 房主離開 | 這場比賽取消，大家回到房間（不給獎勵、不用做數學），由 Playroom 自動指定新房主 |
| 中途加入 | 比賽進行中加入的人，要等下一場 |
| 離開房間 | 按「離開房間」會重新整理網頁回到首頁 |

只想跟電腦對戰的小朋友，不用進好友房間；單機模式完全不會載入或連到 Playroom。

### 連線方式（Playroom Kit，房主模式）

程式在 [js/playroom.js](js/playroom.js)（連線）和 [js/room.js](js/room.js)（房間畫面、表情）。

- **房主**的瀏覽器跑遊戲模擬，每秒送 15 次精簡過的狀態快照（`snap`，不可靠通道，掉了下一次補上）。開賽陣容（`match`）和比賽結果（`result`）走可靠通道。
- **其他玩家**每秒送 30 次輸入（`inp`）。大招、超能力、翻滾用「計數器」表示，封包掉了也不會漏按。
- 自己的角色會先在本機**預測移動**，再慢慢對齊房主的位置；其他角色和球在快照之間補間，子彈依速度自己往前飛。
- Playroom 的 SDK（`playroomkit@0.0.97`，約 1.1MB）只有打開「好友房間」時才從 unpkg 載入。

設定在 [js/config.js](js/config.js) 的 `PLAYROOM`：

| 設定 | 說明 |
| --- | --- |
| `gameId` | **尚未設定**。到 Playroom Dev Portal 建立專案後取得（Configuration → General）。沒填也能連線，但 Console 會出現警告 |
| `maxPlayers` | 每個房間最多幾位真人（4） |
| `snapHz`、`inputHz` | 房主每秒送幾次狀態（15）、其他玩家每秒送幾次輸入（30） |
| `sdk` | SDK 網址，固定版本，升級前請先測試 |

**費用與限制：** Playroom 免費方案每天限 **10 位不重複玩家**，正式上線大概需要付費方案（Lite：每月 10 美元，含 10,000 位月活躍玩家）。Playroom 的 SDK 內建使用統計（以及廣告相關程式），會把使用資料送到 Playroom。

**注意：** 房主的瀏覽器負責跑遊戲，房主網路不好時，大家都會卡頓；房主也有辦法竄改比賽結果。這是房主模式的限制，要改善就需要自架遊戲伺服器。

**本機測試：** 連線功能要用 `http://` 開啟，不能用 `file://`。在專案資料夾執行 `python3 -m http.server 8765`，再用兩個瀏覽器視窗（其中一個用無痕模式）打開 `http://localhost:8765`。

| 正式 | 3 分鐘 | 2 分鐘 |

星光代幣的門檻也分環境：開發環境單次答對 3 題就拿得到，正式環境要 12 題。

這些設定在 `config.js` 每個環境的 `timing`：`matchSecs` 是比賽秒數，`mathSecs` 是數學秒數，`tokenAt` 是拿星光代幣要答對的題數。畫面上的「2 分鐘數學挑戰」這類文字會跟著設定變。

**LootLocker 的環境由 game key 決定：** `prod_` 開頭會連到 LootLocker 的 Live（正式）環境，其他都連到 Development（開發）環境。White Label 登入需要的 `is-development` 標頭會自動跟 key 對齊，不用手動設定。LootLocker 後台的平台設定（White Label Login）、貨幣、排行榜都是**兩個環境分開設定**的。

正式環境目前填的是 `dev_` key，所以實際用的是 `1jjsx26h` 這個遊戲的開發環境。要真正上線時：

1. 在 LootLocker 後台切到 **Live** 環境。
2. 開啟 **White Label Login**，並設定驗證信。
3. 建立並發佈貨幣 `CIN`、`PPT`，開啟 Game API writes。
4. 建立排行榜 `grass_goal_online_math`、`grass_goal_online_wins`，設定同上。
5. 把 `config.js` 正式環境的 `gameKey` 換成 `prod_` 開頭的 key。

如果某個環境的 game key 是空的，那個環境的帳號功能會停用，但遊戲本身照常可以玩。

`domain-key` 和 game key 是給遊戲客戶端使用的公開金鑰，本來就會出現在瀏覽器裡。**不要**把 LootLocker 後台的 server key 或帳號密碼放進前端程式。

### 帳號功能

首頁的「👤 登入 / 註冊」按鈕會打開帳號頁；登入後按鈕會顯示名稱（沒有名稱就顯示 Email）。帳號頁有五個畫面：

| 畫面 | 說明 |
| --- | --- |
| 登入 | 未登入時預設顯示。輸入 Email 和密碼，呼叫 `white-label-login/login`（記住我），再用拿到的 token 開遊戲 session（`game/v2/session/white-label`），並讀取玩家名稱 |
| 建立帳號 | Email、密碼（至少 8 個字元，這是 LootLocker 伺服器的規定）、確認密碼，名稱可以不填（2～16 個字）。呼叫 `white-label-login/sign-up` 後會自動嘗試登入 |
| 註冊完成 | 如果後台規定 Email 驗證後才能登入，建立帳號後會停在這裡，提醒先去收驗證信再登入 |
| 忘記密碼 | 見下一節 |
| 我的帳號 | 顯示名稱和 Email，可以返回首頁、重設密碼或登出 |

**名稱：** 名稱要登入後才能設定（`PATCH game/player/name`）。註冊時填的名稱會先記在裝置上，登入成功時才設定，所以就算要先驗證 Email，名稱也不會遺失。

**自動登入：** 重新打開網頁時，會用記住的 token 呼叫 `white-label-login/verify-session` 確認還有效，再開新的遊戲 session。token 失效就自動登出；連不上網路則先保留登入狀態。

**登出：** 呼叫 `DELETE game/v1/session` 結束遊戲 session，並清掉裝置上的登入資料。就算伺服器那邊失敗，這台裝置也一樣會登出。

### 忘記密碼

登入畫面有「忘記密碼？」，「我的帳號」畫面有「重設密碼」。輸入 Email 後，遊戲會呼叫 `white-label-login/request-reset-password`，LootLocker 寄出重設密碼的信，使用者點信裡的連結，到 LootLocker 提供的網頁設定新密碼；那個網頁的名稱和 Logo 在 LootLocker 後台的平台設定裡調整。

- 為了不透露某個 Email 有沒有註冊過，畫面一律顯示「如果這個 Email 有註冊過，重設密碼的信已經寄出」。
- 寄出後 30 秒內不能再按，避免連按一直寄信。

### 裝置上存了什麼

這台裝置只會記住 Email、名稱、玩家 ID 和 LootLocker 發的登入 token（存在 `localStorage` 的 `brawlAccount_<環境>`），**不會**記住密碼。開發環境和正式環境的登入狀態分開存。所有 LootLocker 請求都有 15 秒逾時。

**LootLocker 後台需要先做的設定：** 到後台啟用 **White Label Login** 平台，並設定驗證信的寄件資訊。還沒啟用之前，API 會回傳 `platform is not enabled`，畫面上會顯示「帳號功能還沒開通」。

### 遊戲迴圈與連線架構

為了之後的多人連線，輸入、模擬、畫面是分開的：

```
裝置(鍵盤/滑鼠/搖桿) ─ readLocalInput() ─┐
                                        ├→ Net.collectInputs() → update(dt, inputs) → draw()
其他玩家的輸入(連線時) ──────────────────┘          ↑ 只有房主跑            ↑ 鏡頭跟著 G.me
```

- **輸入資料**（[js/input.js](js/input.js)）：移動方向、是否攻擊、瞄準（滑鼠用場地座標 `tx`、`ty`，搖桿用角度 `aim`）、大招／超能力／翻滾。可以轉成 JSON，連線時直接送出。
- **角色**：每個角色都有 `ctrl`（`human` 或 `ai`）、`pid`（真人玩家 id）和 `mods`（加成倍率）。`update()` 依 `pid` 找出該玩家這一幀的輸入；電腦角色照 AI 行動。
- **加成**：`mods` 由玩家的配置（`loadout`：商店升級、英雄等級、配件、造型）算出來，所以每位真人的升級和配件只作用在自己的角色上。電腦角色的加成都是中性值（不加成）。
- **開賽**：`reset(players)` 接受最多 4 位真人。每位真人依所選英雄決定隊伍，優先坐英雄原本的位置；同隊同位置已經有人時改坐其他空位，其餘位置由電腦補滿 7 對 7。
- **本機玩家**：`G.me` 是本機玩家角色的位置，鏡頭、HUD、「你·」標籤和畫面震動都跟著它。
- **連線層**（[js/net.js](js/net.js)）：遊戲只透過 `Net` 物件決定誰是房主、有哪些玩家、輸入從哪裡來、結果送到哪裡。單機版是 `LocalNet`，好友房間是 `PlayroomNet`（[js/playroom.js](js/playroom.js)），進房間時把 `Net` 換掉。

### 經濟系統與排行榜（LootLocker）

設定在 [js/config.js](js/config.js) 的 `LL_ECONOMY`，同步邏輯在 [js/economy.js](js/economy.js)。

| LootLocker | 用途 |
| --- | --- |
| 貨幣 `CIN` | 💰 金幣 |
| 貨幣 `PPT` | ⚡ 戰力能量 |
| 排行榜 `grass_goal_online_math` | 分數 = 累計**答對題數**；metadata = 累計**答題數**（數字字串） |
| 排行榜 `grass_goal_online_wins` | 分數 = 累計**勝場數**；metadata = 累計**出賽數**（數字字串，輸、平手也算） |

**沒登入時：** 金幣和能量只存在這台裝置，排行榜不記錄。

**登入時：** 把裝置上累積的金幣和能量轉進帳號錢包，之後畫面上顯示的都是帳號錢包的餘額。每次登入都會轉，所以沒登入時賺的不會不見；登出後，裝置上的金幣和能量是 0，從頭累積。

**交易方式：** 賺錢（credit）、花錢（debit）、排行榜更新都先放進佇列（存在 `localStorage`），依序送給 LootLocker：

- 連不上網路就留在佇列裡，30 秒後或下次登入時補送。
- 伺服器拒絕的交易（例如餘額不足）會丟掉，並以伺服器的餘額為準。
- 排行榜沒有「累加 metadata」的 API，所以每次都是先讀取目前的分數和 metadata，加上這次的數字再送出。
- 遊戲 session 過期時，會用「記住我」的 token 自動重開。

「我的帳號」畫面會顯示同步狀態，例如「☁️ 已同步」、「還有 N 筆資料等待上傳」，或錯誤訊息。

**LootLocker 後台需要的設定：**

| 項目 | 設定 |
| --- | --- |
| 貨幣 CIN、PPT | 開啟 **Game API writes**（沒開的話「我的帳號」會顯示警告，金幣能量存不進帳號） |
| 兩個排行榜 | 類型設為 **Player**（member_id 用玩家 ID）、開啟 **Game API writes**、開啟 **Metadata** |
| 兩個排行榜 | 開啟 **Overwrite score on submit**：輸球時勝場數不變但出賽數會增加，沒開的話 LootLocker 可能只保留最高分那筆，metadata 不會更新 |

**注意：** 這些寫入都是從玩家的瀏覽器直接送出的，懂技術的人可以自己呼叫 API 改金幣或分數。LootLocker 建議重要的寫入改由後端伺服器處理；目前這個專案是純靜態網頁，沒有後端。

### 存檔

所有進度（金幣、能量、代幣、英雄、配件、造型、還沒完成的數學挑戰）都存在瀏覽器的 `localStorage`（key：`brawlSave`）。換瀏覽器、換裝置或清除網站資料，進度就會不見。
