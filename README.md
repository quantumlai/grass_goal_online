# 草叢大亂鬥 ⚽

7 對 7 的俯視角足球對戰遊戲。用射擊和技能把對手打倒，把球踢進對方球門！

## 怎麼開始

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝或架伺服器。電腦和手機都可以玩。

1. 首頁用 `‹` `›` 切換角色，選哪個角色就等於選了他所屬的**隊伍**和**位置**。
2. 按 **出擊!** 開始比賽。你操控自己選的角色，其他 13 名隊友與對手都由電腦控制。

## 勝負規則

| 項目 | 規則 |
| --- | --- |
| 比賽時間 | 3 分鐘 |
| 獲勝條件 | 先進 **3 球**的隊伍立刻獲勝；時間到則比分高者勝，同分算平手 |
| 進球 | 球進入對方球門區域就得分。藍隊攻右邊、紅隊攻左邊，踢進自家球門會算對方得分 |
| 進球後 | 停頓約 2 秒後重新開球：球回到中圈，所有人回到開場位置並補滿血量 |

### 比賽結束獎勵

| 結果 | 金錢 💰 | 獎盃 🏆 |
| --- | --- | --- |
| 勝利 | +$150 | +8 |
| 平手 | +$100 | 不變 |
| 落敗 | +$50 | −3（最低為 0） |

金錢、獎盃和商店升級都會自動存在瀏覽器裡（`localStorage`），換瀏覽器或清除網站資料就會不見。

| 移動 | `W` `A` `S` `D` | 左側搖桿 |
| 瞄準 / 攻擊 | 滑鼠瞄準、點擊射擊 | 右側搖桿瞄準，放開時射擊 |

## 場上機制

### 帶球與射門
- 碰到球就能帶著球走。
- 球在腳邊時按攻擊鍵，會把球往瞄準的方向踢出去，而不會射擊。
- 爆炸類攻擊也會把附近的球炸開。

### 攻擊、大招、超能力
- **普通攻擊**：每個角色的攻擊方式都不一樣，像是散彈、狙擊、拋物線炸彈或近身斬擊。
- **大招**：攻擊和命中敵人都會累積大招能量，集滿 100% 後按大招鍵施放，施放後能量歸零。
- **超能力**：每個角色各有一招，用完要等冷卻（4～9 秒），不需要累積能量。
- **翻滾**：短暫衝刺，翻滾中**不會受到傷害**，冷卻 3.5 秒。

### 受傷、擊倒與回血
- 血量歸零就會被擊倒，**3 秒**後在自己的開場位置重生。
- 連續 4 秒沒有受到攻擊，就會開始自動回血（每秒 25 點）。
- 被擊倒時會掉落一個綠色**強化方塊**，任何人撿到都能得到：
  - 血量上限 +10
  - 傷害 +10%（可以累加；被擊倒時強化全部歸零）

### 草叢
躲進草叢後，敵人就看不到你。不過敵人靠得很近（約 2 個身位內）時還是會被發現。

## 隊伍與角色

兩隊的陣型固定為：**1 守門員、3 後衛、2 中場、1 前鋒**。如果某個位置的角色比名額多，開賽時電腦會隨機挑選上場的角色。

每個角色都有一個常駐的**特性**，不需要啟動就一直有效。

## 專案結構

```
index.html        頁面結構
css/style.css     樣式
js/
  setup.js        畫布、尺寸、地圖（牆、草叢）
  characters.js   角色資料表
  state.js        存檔、升級、隊伍建立、重置比賽
  input.js        觸控、鍵盤、滑鼠輸入
  combat.js       射擊、技能、翻滾、踢球、進球、受傷
  update.js       每一格畫面的遊戲邏輯與比賽結算
  render.js       繪製場地與角色
  home.js         首頁與選角
  roster.js       角色列表與詳細頁
  shop.js         商店
  main.js         主迴圈與啟動
```

JS 檔案共用全域變數，`index.html` 裡 `<script>` 的載入順序不能更動。
